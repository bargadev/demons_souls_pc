Demon's Souls for Windows
=========================

No game files or PS3 firmware are included. You need:
  - your own dump of the Demon's Souls disc: BLUS30443 (US), BLES00932 (EU),
    BCJS30022 (JP) or BCAS20071 (Asia). Do not install game updates: the 60 FPS and
    other patches only work on the original disc version.
  - the official PS3 firmware, PS3UPDAT.PUP, from PlayStation's website.

First start
  1. Start "Demons Souls.exe".
  2. Game folder: choose the folder of your dump (the one with PS3_GAME inside).
  3. PS3 firmware: press "Install firmware...", choose PS3UPDAT.PUP and close the
     RPCS3 window when the installation finishes.
  4. Press PLAY.

The first start compiles the game's code and shaders and takes a few minutes; later
starts are fast. "Play Demons Souls.exe" starts the game straight away with your saved
settings (good for a desktop shortcut or Steam).

Controls
  Controllers and keyboard are set in "Controls and advanced settings (RPCS3)": open
  Configuration > Gamepads and choose your controller (XInput for Xbox pads, DualSense
  or DualShock 4 for PlayStation pads).

Known issues
  - Above 60 FPS the game's physics break; the launcher keeps the limit at 60.
  - "Install firmware..." and the advanced settings open the RPCS3 window; close it
    when you are done.
